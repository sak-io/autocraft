# Receipt Tally (owner's idea, in the owner's words)
I want a small tool that reads the CSV files my bank lets me download, sorts each transaction into categories using rules I write in a text file, and prints a monthly spending summary. I'll run it once a month. It must never send my data anywhere.
Owner: Sam, not a developer. Runs Python 3 on a laptop. Bank CSVs differ per bank (Sam has two banks, one uses DD/MM/YYYY and a single signed Amount column, the other uses YYYY-MM-DD with separate Debit and Credit columns).
