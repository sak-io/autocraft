# Traceability matrix: spec acceptance criteria to tests

Every AC in `docs/specs/classbook.md` (including AC-4b.x and the change-log items) and the answered questions that
change behaviour (Q1, Q2, Q3, Q5, Q6, Q7, Q8). Test names are `file::test` (short names; parametrised tests count as one).
Files: `tests/test_*.py` are the per-task tests (T1-T6); `tests/qa/*` and `tests/e2e/*` are T7. **Bold** = added by T7.
Status: COVERED = at least one test that fails if the AC is broken (mutation-checked where the QA summary says so);
PARTIAL = covered except the named gap, which is a reported defect.
